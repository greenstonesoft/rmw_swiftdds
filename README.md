# rmw_swiftdds
rmw_swiftdds: ROS 2 RMW implementation for SWIFT DDS — enables ROS 2 communication via SWIFT DDS middleware. This package implements the ROS 2 RMW API to bridge ROS 2 communication (publish/subscribe, services, actions) with SWIFT DDS — a high-performance DDS middleware compliant with the OMG DDS standard. It supports all core ROS 2 features.
